Это материал для изучения и личного объяснения. Преподаватель разрешает AI, но спрашивает о любой строке кода: текст нужно понять, а не просто зачитать.

5. Открыть README: `Responsive`, `Why this tool`, AI. На официальной защите преподаватель просит GitHub и Pages; до публикации доступна только локальная демонстрация.

### Что объяснить

- **Flexbox:** раскладывает элементы вдоль одной оси, здесь шапку и кнопки.
- **Grid:** задаёт сетку карточек сразу по строкам и колонкам.
- **minmax(0, 1fr):** разрешает колонке сжиматься, не раздувая страницу из-за содержимого.
- **clamp(min, preferred, max):** размер растёт с экраном, но остаётся в пределах.
- **Nesting:** правило дочернего элемента записывается внутри родительского; `&` обозначает сам родительский селектор.
- **:has():** выбирает родителя по состоянию/наличию дочернего элемента. Здесь подсвечивает заголовок карточки, когда наведён её img.
- **Почему без Sass:** переменные и вложенность работают в самом браузере; компиляция для этой страницы не нужна.

## №4 — план своей записи на 2–3 минуты

### 0:00–0:25 — проект и тесты

### 0:25–1:05 — counter

Открыть `counter`. При вызове фабрики создаётся `current`. Возвращённые функции продолжают обращаться к нему после завершения фабрики: это замыкание. `inc` увеличивает ту же переменную, `dec` уменьшает, `value` читает. У двух вызовов фабрики разные переменные, поэтому два счётчика не влияют друг на друга. Пример: `const a = counter(); const b = counter(); a.inc();` — у `a` значение 1, у `b` 0.

### 1:05–1:50 — memoize

Открыть `memoize`. Кеш создаётся один раз при оборачивании функции; возвращённая функция замыкает его. При каждом вызове выбирается путь по `this` и аргументам в дереве `Map`. Если на этом пути уже есть ключ `resultKey`, возвращается сохранённое значение. Иначе вызывается исходная функция, результат записывается и возвращается. `has()` нужен, потому что `undefined` тоже может быть законным результатом. Объекты сравниваются по ссылке, поэтому два разных объекта не смешиваются, а исходный контекст сохраняется через `fn.apply(this, args)`.

### 1:50–2:30 — Store, SortedStore и super

`Store` хранит массив в приватном поле `#items`. Getter `items` и `find` возвращают копии, поэтому внешний код не может обойти проверки прямым изменением товара. Статический `Store.validate` вызывается у класса, без создания экземпляра. В `SortedStore.add` вызов `super.add(item)` использует реализацию родителя: проверки и добавление остаются в одном месте. Затем возвращается `this.items`; переопределённый getter получает копию через `super.items` и сортирует её. Это наследование и переопределение метода, а не вторая независимая реализация Store.

### 2:30–2:50 — ограничения и AI

Указать AI-инструмент, как в README. Объяснить, что `deepClone` поддерживает объекты, массивы и Date, а циклы не требовались. Для `memoize` результат должен быть стабильным при одинаковых входных значениях; кеш не узнаёт о мутации ранее переданного объекта.

## Вопросы по №4

- **Почему не JSON-клонирование?** Оно преобразует Date в строки, теряет некоторые значения и не соответствует условию. Здесь Date обрабатывается явно, массив — map, объект — рекурсивное копирование свойств.
- **map / filter / reduce?** map преобразует каждый элемент; filter отбирает элементы; reduce накапливает итог. Они показаны в deepClone, inStockNames, groupBy и total.
- **Почему деньги в сотых?** Двоичные дроби вроде 0.1 представляются приблизительно. Складываются целые сотые, затем итог делится на 100.
- **Пустой Store?** items пустой, total равен нулю.
- **Повтор имени?** Отклоняется, количество меняется отдельным методом.
- **Отрицательное количество?** Ошибка; ноль разрешён.
- **Разница getter и метода?** Getter читается как `store.items`, метод вызывается как `store.total()`.
- **Что означает #?** Это приватное поле класса, недоступное обычным обращением снаружи.
- **Что означает static?** Метод принадлежит классу, здесь `Store.validate`, а не конкретному магазину.
- **Что такое тест крайнего случая?** Проверка пустого/нулевого/неправильного или граничного входа, где обычный пример не доказывает правильность.

### Что такое делегирование

Клик всплывает от кнопки к контейнеру списка. Контейнер получает его одним обработчиком и находит кнопку через `closest`. Данные `data-action` и `data-name` определяют операцию и товар. Новые строки создаются без отдельных слушателей, и обработчик продолжает работать после `replaceChildren()`.
