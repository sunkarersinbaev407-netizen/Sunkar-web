# Как загрузить SunkarSABAQ на GitHub и отправить преподавателю

## Что внутри
- `landing-ersinbaev/` — лабораторные №2 и №3 (лендинг Qarjy и адаптивность).
- `js-core-ersinbaev/` — лабораторная №4 (JavaScript-функции, Store и тесты).
- `dom-store-ersinbaev/` — лабораторная №5 (интерфейс списка покупок).
- `DEFENSE.md` — материалы для подготовки к защите.

## Вариант: один общий репозиторий
1. Распакуйте архив на компьютере.
2. Войдите на https://github.com и нажмите **New repository**.
3. Назовите репозиторий `SunkarSABAQ`, выберите **Public** и создайте его.
4. На странице репозитория выберите **Add file → Upload files**.
5. Откройте распакованную папку `SunkarSABAQ` на компьютере и перетащите её содержимое (папки `landing-ersinbaev`, `js-core-ersinbaev`, `dom-store-ersinbaev`, файлы README и DEFENSE) в окно загрузки. Не загружайте сам ZIP как единственный файл.
6. Внизу напишите сообщение коммита, например `Add lab projects and documentation`, затем нажмите **Commit changes**.
7. После загрузки скопируйте адрес репозитория и отправьте его преподавателю.

## Как включить GitHub Pages для лендинга
1. В репозитории откройте **Settings → Pages**.
2. В разделе Build and deployment выберите **Deploy from a branch**.
3. Выберите ветку `main` и папку `/(root)`, затем нажмите **Save**.
4. Подождите, пока GitHub опубликует сайт. Лендинг должен открываться по адресу вида:
   `https://ВАШ-USERNAME.github.io/SunkarSABAQ/landing-ersinbaev/`
5. Приложение №5 должно открываться по адресу вида:
   `https://ВАШ-USERNAME.github.io/SunkarSABAQ/dom-store-ersinbaev/`

Замените `ВАШ-USERNAME` на свой настоящий GitHub username. Адреса выше — шаблоны, они не работают до публикации.

## Важно
- Этот архив подготовлен для загрузки, но GitHub-репозиторий за вас не создаётся, и ссылка преподавателю автоматически не отправляется.
- Не выдавайте один первичный коммит за несколько коммитов разработки. Если преподаватель требует несколько содержательных коммитов, добавляйте реальные изменения отдельными коммитами.
- Проверьте README и требования преподавателя перед отправкой. Для лабораторной №4 запустите `npm install`, затем `npm test` в папке `js-core-ersinbaev`.
